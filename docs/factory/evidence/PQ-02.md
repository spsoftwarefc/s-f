# PQ-02 — independent policy / reference-grant source candidate

**Not production-qualified.** New optional APIs strictly digest-pin a separately obtained provider query policy before calling the existing GitHub provider metadata verifier; they also verify a single-operator HMAC reference grant over exact effect, target, environment, artifact, policy and epoch with expiry. No candidate-supplied policy is trusted without an operator-independent digest.

The HMAC variant is limited to an independently custodied *single-operator* secret. Its local receipt always sets `effectAuthorized=false` and `accepted=false`: it does not prove credential custody, protected CI checkout identity, artifact bytes, external revocation, durable replay prevention or destination admission. A public-key adapter is required if verifier separation becomes a requirement. No real provider run or destination was queried during implementation; unit tests use mocks.

Targeted tests cover policy-digest substitution, scoped grant MAC, altered destination, wrong effect/environment/policy, stale revocation epoch and expiry. Test execution and CI statuses are pending.
