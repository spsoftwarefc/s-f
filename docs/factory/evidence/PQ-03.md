# PQ-03 — exact-byte retained build source candidate

An opt-in local store now stages caller-declared build records and a bundle under SHA-256-addressed filenames, using exclusive creation, fsync and strict later byte revalidation. An already present matching record is reusable without invoking a build; altered or partial stored material is rejected. Unit tests cover idempotency, digest mismatch, mutation, conflicts, expiry and symlinks.

**Not production-qualified.** The candidate manifest is not a provenance signature. Builder identity, dependency/action pin verification, SBOM generation, remote immutable retention, evidence custodian and real published artifact verification are not implemented. No release/publication/deploy is performed. Unit and hosted CI results remain to be measured against the stable stack head.
