# s-f — Software Factory

s-f is a repository-local software production system for planning, implementing, verifying, reviewing, releasing and operating software changes.

Current state: **SF-07 portability qualification candidate**. SF-00–SF-06 provide a development-preview portable installation layer; G2 must pass exact-candidate Linux/Windows tests before this stack is accepted. SF-08–SF-19 planning, execution, verified CI, security, distribution, deployment and operations remain pending. This is not a production-qualified factory.

Start with:
- `AGENTS.md` for repository operating boundaries.
- `docs/factory/WORKFLOW.md` for the lifecycle.
- `docs/factory/WORK_ORDER.md` for package checkpoints.
- `docs/factory/PROJECT.md` for this repository's adapter.
- `docs/factory/work-orders/SF-07.md` for the current package and `docs/factory/SF07_QUALIFICATION.md` for its acceptance matrix.
- `docs/factory/SF06_LIFECYCLE.md` for opt-in installation, upgrade, removal and recovery limits.

The original CTJ bot repository is provenance only. s-f must not inherit trading authority, exchange procedures, credentials, runtime state or historical bot completion claims.
