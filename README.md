# s-f — Software Factory

s-f is a repository-local software production system for planning, implementing, verifying, reviewing, releasing and operating software changes.

Current state: **SF-00 baseline reconciliation**. The repository is not yet a production-qualified factory and does not claim CI enforcement that has not been installed and exercised.

Start with:
- `AGENTS.md` for repository operating boundaries.
- `docs/factory/WORKFLOW.md` for the lifecycle.
- `docs/factory/WORK_ORDER.md` for package checkpoints.
- `docs/factory/PROJECT.md` for this repository's adapter.
- `docs/factory/work-orders/SF-00.md` for the active package.

The original CTJ bot repository is provenance only. s-f must not inherit trading authority, exchange procedures, credentials, runtime state or historical bot completion claims.
